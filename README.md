# OpenScope OSINT (Android)

Android-приложение на Kotlin + Jetpack Compose. Интерфейс на русском, без root и без собственного сервера.

## Реализовано

- **Username OSINT** — пассивные HTTP-проверки публичных страниц GitHub, Reddit, GitLab, Pinterest и Medium. Ответы 200/404/403/429 показываются отдельно; неоднозначные ответы не считаются подтверждением.
- **Email OSINT** — проверка синтаксиса адреса и публичных DNS A/MX-записей домена почты. Приложение не пытается входить в почтовый ящик и не подтверждает существование конкретного ящика.
- **Domain OSINT** — публичные DNS A/AAAA/MX/NS-записи через DNS-over-HTTPS Cloudflare и доступные регистрационные сведения RDAP.
- **Локальное объяснение** — встроенные правила на русском языке объясняют смысл находок и ограничения результатов; данные не отправляются в генеративный ИИ.

## Важно о приватности и сети

Обработка результатов выполняется на Android. Для запросов к открытым источникам нужен интернет; запросы направляются проверяемым публичным сайтам, Cloudflare DNS и RDAP. Не вводите чужие чувствительные данные без законного основания. Это пассивный анализ открытых источников, а не подтверждение личности или владения аккаунтом.

## Что пока не реализовано

- EXIF-анализ локальных изображений;
- полноценное сохранение истории и экспорт отчётов;
- локальная генеративная LLM. В текущей версии объяснение — детерминированный локальный аналитический помощник, а не нейросеть;
- интеграция Maigret/Sherlock/SpiderFoot и других крупных движков. Они не заявляются как подключённые.

## Сборка

GitHub Actions → **Android APK** → артефакт `OpenScope-OSINT-APK`.

Требования локальной сборки: JDK 17, Android SDK 35, Gradle 8.9, minSdk 26.

## Принципы безопасности

Только открытые источники, разрешённые проверки и уважение к лимитам сайтов. Нет обхода авторизации, эксплуатации уязвимостей, скрытого отслеживания или сбора закрытых данных.
