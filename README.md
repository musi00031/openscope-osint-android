# OpenScope OSINT — Android

Локально ориентированное Android-приложение для пассивного анализа открытых источников. Интерфейс на русском языке, без root и без собственного сервера.

## Функции текущей версии

- **Username OSINT:** проверка публичных страниц профилей на GitHub, Reddit, GitLab, Pinterest и Medium. HTTP-ответы помечаются как предварительные сигналы, а не доказательство принадлежности аккаунта.
- **Email OSINT:** синтаксис email, публичные DNS-записи MX/A/AAAA/TXT домена. Не проверяет существование конкретного почтового ящика.
- **Domain OSINT:** публичные DNS-записи A/AAAA/MX/NS/TXT/CAA и доступные регистрационные сведения RDAP.
- **IP OSINT:** публичный IP, страна/регион/город, ASN и провайдер через внешний IP-справочник. Геолокация приблизительная.
- **URL Analysis:** разбор протокола, хоста, порта и HTTP-ответа. Не является антивирусом или проверкой репутации.
- **Image & Metadata:** выбор локального изображения, чтение доступных EXIF-полей, GPS при наличии и SHA-256. Сам файл не загружается на сервер.
- **История:** локальное сохранение списка исследований на устройстве.
- **Экспорт:** отправка текстового отчёта через Android share sheet.
- **Объяснения:** встроенные русскоязычные правила поясняют значения и ограничения результатов. Это локальный rule-based помощник, а не генеративная LLM.

## Сеть и приватность

Анализ изображения выполняется локально. Для username-проверок приложение обращается к публичным сайтам; DNS-запросы идут через Cloudflare DNS-over-HTTPS; RDAP через rdap.org; IP-геоданные через ipwho.is. Эти внешние сервисы получают соответствующие запросы и проверяемые идентификаторы. Не вводите чувствительные данные без законного основания.

## Ограничения

Это не «все данные интернета» и не средство деанонимизации. Нет обхода авторизации, доступа к закрытым аккаунтам, скрытого наблюдения, взлома, проверки паролей или гарантированной идентификации владельца. Ответы сайтов могут быть ограничены антибот-защитой, регионами и лимитами.

Интеграция Maigret/Sherlock/SpiderFoot и полноценной локальной генеративной нейросети в этой сборке не заявляется.

## Сборка

GitHub Actions → **Android APK** → артефакт `OpenScope-OSINT-APK`.

Требования: JDK 17, Android SDK 35, Gradle 8.9, minSdk 26.
