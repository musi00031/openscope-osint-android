# OpenScope OSINT (Android)

Локальный Android-проект на Kotlin + Jetpack Compose. Русский интерфейс, без root, без обязательного VPS.

## Текущий статус

Это **MVP-каркас интерфейса**, а не готовый набор подключённых OSINT-движков. В приложении есть:
- главная панель и типы исследований;
- каталог модулей;
- локальная история подготовленных задач;
- базовая архитектура интерфейса;
- GitHub Actions для сборки debug APK.

Внешние проекты Maigret, Sherlock, SpiderFoot, Recon-ng, Holehe, theHarvester и Social Analyzer пока не встроены. Перед интеграцией каждого движка нужно отдельно проверить лицензию, Python/Android-совместимость, сетевые требования и ограничения источников. Не следует заявлять, что модуль работает, пока адаптер и тесты не добавлены.

## Требования

- Android Studio с Android SDK 35 (для локальной сборки) либо GitHub Actions;
- JDK 17;
- Gradle 8.9;
- minSdk 26.

## Сборка локально

```bash
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка через GitHub

1. Загрузите содержимое проекта в корень репозитория и отправьте в ветку `main`.
2. Откройте **Actions → Android APK**.
3. Скачайте артефакт `OpenScope-OSINT-APK`.

## План интеграции

1. Слой `ModuleRunner` и интерфейс результата.
2. Локальные безопасные утилиты (EXIF для выбранных пользователем файлов, нормализация домена, проверка формата).
3. Проверенные адаптеры username/email/domain для публичных источников.
4. Экспорт JSON/CSV/HTML и локальная база Room.
5. По отдельности оценить возможность запуска Python-движков в Android/Termux и их лицензии.

## Принципы безопасности

Используйте приложение для собственных данных, разрешённых аудитов и публичной информации. Не реализуйте обход авторизации, сбор закрытых данных, скрытое отслеживание, массовый спам или эксплуатацию уязвимостей. Уважайте условия сайтов, rate limits и законодательство.
