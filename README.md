# OpenScope OSINT — Android

Локально ориентированное Android-приложение для пассивного анализа открытых источников. Русский интерфейс, без root и без собственного сервера. Обработка правил и результатов выполняется на устройстве; сетевые запросы идут напрямую к открытым источникам.

## Модули

- **Username OSINT:** локально включённый набор правил WhatsMyName. При запуске проверяется до 400 публичных HTTPS GET-площадок; NSFW, POST, CAPTCHA, Cloudflare, авторизованные и другие защищённые источники исключены. Положительное совпадение — только кандидат профиля.
- **Поиск публичных упоминаний:** четыре тематических варианта поиска через DuckDuckGo HTML, Wikipedia RU/EN, Wikidata RU/EN и GDELT News. Результаты объединяются, удаляются дубли по URL; в отчёте до 30 страниц с заголовками, фрагментами, ссылками и сводкой доменов. Это не идентификация личности: однофамильцы возможны. Модуль не ищет домашние адреса, частные контакты, родственников или местоположение.
- **Email OSINT:** синтаксис email и публичные DNS-записи MX/A/AAAA домена. Не проверяет существование конкретного почтового ящика.
- **Domain OSINT:** публичные DNS-записи A/AAAA/MX/NS/TXT/CAA, регистрационные сведения RDAP и пассивное обнаружение имён поддоменов по журналам Certificate Transparency (crt.sh).
- **IP OSINT:** проверка публичного IPv4/IPv6, страна/регион/город, ASN и провайдер через ipwho.is. Геолокация приблизительная и не показывает адрес человека.
- **URL Analysis:** разбор протокола, хоста, порта и HTTP-ответа; блокировка обращений к локальным и частным сетевым адресам. Не является антивирусом или проверкой репутации.
- **Image & Metadata:** локальный выбор изображения, доступные EXIF-поля, GPS при наличии и SHA-256. Файл не загружается на сервер.
- **Отчёты:** расширенная сводка, результаты, ссылки/источники, уровень сигнала, методология, ограничения и дата формирования.
- **История:** локальное сохранение списка исследований.

## Используемые открытые проекты и лицензии

- WhatsMyName dataset — https://github.com/WebBreacher/WhatsMyName, CC BY-SA 4.0. Данные загружаются GitHub Actions из официального репозитория в assets APK. В интерфейсе и документации указывается атрибуция исходному проекту. Лицензия набора данных CC BY-SA 4.0.
- Maigret, Sherlock и SpiderFoot изучены как более тяжёлые OSINT-проекты. Их Python-движки не встраиваются напрямую в Android APK: для этого потребовалась бы отдельная Python runtime-среда и заметно больший APK. В текущую сборку они не включены и не должны считаться запущенными.

## Сеть и приватность

- Проверки username обращаются к публичным страницам площадок; сайту передаётся проверяемый никнейм.
- Поиск публичных упоминаний передаёт имя DuckDuckGo, Wikipedia, Wikidata и GDELT; эти сервисы получают поисковый запрос.
- DNS-запросы идут через Cloudflare DNS-over-HTTPS; RDAP — через rdap.org; IP-геоданные — через ipwho.is.
- Анализ изображений выполняется локально; сами файлы не отправляются.
- Не вводите закрытые или чувствительные сведения без законного основания. Модуль поиска человека ограничен публичными веб-упоминаниями и не предназначен для поиска домашнего адреса, скрытых контактов, паролей или отслеживания местоположения.

## Ограничения

Это не «все данные интернета» и не средство деанонимизации. Нет обхода авторизации, доступа к закрытым аккаунтам, взлома, проверки паролей или гарантированной идентификации владельца. Сайты могут менять разметку, ограничивать запросы и выдавать ложные/неполные ответы. Совпадение имени или никнейма само по себе не связывает аккаунты с одним человеком.

## Сборка

GitHub Actions → **Android APK** → артефакт `OpenScope-OSINT-APK`.

Workflow скачивает актуальный `wmn-data.json` из официального репозитория перед сборкой. Требования: JDK 17, Android SDK 35, Gradle 8.9, minSdk 26.
